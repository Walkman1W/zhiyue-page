# 🎮 之玥的游戏世界

之玥通过 AI 创作的小游戏合集。

## 项目结构

```
/
├── index.html          # 游戏大厅首页
├── games/              # 所有游戏
│   ├── demo-game/      # 示例游戏
│   │   └── index.html
│   ├── snake/          # 贪吃蛇
│   │   └── index.html
│   └── ...            # 更多游戏
└── README.md
```

## 如何添加新游戏

1. 在 `games/` 目录下创建新文件夹（如 `games/my-game/`）
2. 在文件夹里放一个 `index.html`
3. 在首页 `index.html` 的游戏列表里添加卡片
4. 提交并推送，自动部署！
